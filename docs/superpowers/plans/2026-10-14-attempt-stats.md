# 시도·비용 통계 화면 계획

**목표:** 3회차부터 이어 온 핵심 공식 **"완성 1편 비용 = 시도 1회 비용 × 시도 횟수"**를 실제 작업 기록으로 보여 준다.
몇 번 만에 승인했는지, 왜 거절했는지, 완성 1편에 평균 얼마가 들었는지를 한 화면에서 본다. 영상 1편당 추가 크레딧 0.

**브랜치:** `source-upload` 작업 트리 위에서 이어서(1번 미커밋 — 커밋할 때 파일 단위로 나눔). 커밋은 사용자가 요청할 때만.

## 무엇을 세나 (워커 `src/pipeline/stats.js` — 순수 함수 `jobStats(jobs)`)

대상: 미리보기 흐름 작업(`previewRequired`)만. 테스트 모드 워커는 테스트 작업만, 실제 모드는 실제 작업만 센다(섞이지 않게).
로그인 사용자 기준(`x-owner-id`)으로 자기 작업만.

| 값 | 정의 |
|---|---|
| 작업 수 / 승인 / 완성 | 미리보기 작업 수, 승인된 작업 수, `status: done` 수 |
| 평균 미리보기 시도 | 승인된 작업에서 승인까지 쓴 미리보기 수(실패 제외)의 평균 |
| 첫 시도 승인률 | 승인된 작업 중 첫 미리보기를 승인한 비율 |
| 실패한 미리보기 | 환불되어 횟수에 안 세는 시도 수 |
| 거절 사유 | 거절된 시도의 사유별 건수(얼굴·제품·동작·배경·기타), 많은 순 |
| 완성 1편 평균 비용 | 완성 작업의 `jobTotals` 평균 — 미리보기 / 나머지 구간 / 선택 단계로 나눠서, 크레딧과 원화 |
| 목표 대비 | 목표 30,000원(정해진 목표)과 비교 |

## 화면

오른쪽 아래 "내 작업" 옆 **통계** 버튼 → 패널: 숫자 타일(완성 수, 평균 시도, 첫 시도 승인률, 완성 1편 평균 비용 vs 목표),
공식 한 줄("미리보기 1회 35 × 평균 N회 + 나머지 … = 평균 …"), 거절 사유 가로 막대. 테스트 모드면 "실제였다면" 기준임을 표시.
작업이 없으면 빈 상태 안내.

## 테스트 (먼저 작성)

- `jobStats`: 승인까지 시도 수 평균(실패 제외), 첫 시도 승인률, 거절 사유 집계·정렬, 완성 평균 비용 분해, 미리보기 없는 작업·0건 처리.
- `GET /stats`: 소유자 필터, 테스트/실제 모드 분리.
- 웹: `getStats` 클라이언트, 공식 문구 만드는 순수 함수.
