# 노드 캔버스 UI 구현 계획 (서브 프로젝트 1)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 기존 워커 API(`localhost:4000`, 이미 완성·검증됨)를 시각적으로 조작하는 React Flow 기반 노드 캔버스 웹 앱을 만든다. 완료 기준: 브라우저에서 유튜브 URL + 캐릭터 사진을 노드에 입력하고 "실행"을 누르면, 노드들이 실시간으로 상태를 반영하며 최종적으로 결과 영상을 미리보기·다운로드할 수 있다.

**Architecture:** Next.js(App Router) 클라이언트 컴포넌트 하나(`Canvas.tsx`)가 React Flow의 노드/엣지 상태를 관리한다. 5개 고정 노드(영상 입력/캐릭터 입력/생성/병합/결과)는 각각 독립된 프레젠테이션 컴포넌트이며, `lib/workerApi.ts`를 통해 기존 워커 Express API를 브라우저에서 직접 호출(fetch)한다. 노드 연결선은 사용자가 자유롭게 재배치할 수 있지만 실행 로직과는 무관하다(시각적 요소).

**Tech Stack:** Next.js 15 (App Router, TypeScript), React 19, `@xyflow/react` 12, Tailwind CSS 3, Vitest(순수 함수 테스트용)

**Spec:** `docs/superpowers/specs/2026-09-15-canvas-ui-design.md`

## Global Constraints

- 세그먼트별 개별 노드를 만들지 않음 — "생성" 노드 하나가 `job.segments` 배열을 집계해서 보여줌
- 노드 연결선은 자유롭게 드래그해서 재배치 가능하지만, 실행에는 영향을 주지 않음 (서브 프로젝트 2에서 다룰 범위)
- 여러 job 동시 관리/이력 목록은 범위 밖 — 캔버스는 항상 "가장 최근에 실행한 job 하나"만 추적
- 워커 API는 수정하지 않음 — 이미 완성된 `POST /jobs`, `GET /jobs/:id`, `GET /jobs/:id/result`만 그대로 사용
- 폴링 주기는 2초
- 캐릭터 이미지는 정확히 1개 (워커 API 제약과 동일)

## 사전 준비물

- `worker/` 서비스가 로컬에서 `npm start`로 떠 있어야 함 (기본 포트 4000)
- Node.js 20 이상 (Task 2 테스트가 전역 `File` 클래스를 사용하는데, 이는 Node 20부터 안정적으로 제공됨 — 워커 쪽 "18 이상"보다 높은 버전 필요)

`web/lib/workerApi.ts`:

```ts
export type JobSegment = {
  index: number;
  path: string;
  startSeconds: number;
  endSeconds: number;
  status: 'pending' | 'done' | 'failed';
  resultPath: string | null;
  error?: string;
};

export type Job = {
  id: string;
  youtubeUrl: string;
  characterImagePaths: string[];
  status: 'pending' | 'downloading' | 'segmenting' | 'generating' | 'merging' | 'done' | 'failed';
  segments: JobSegment[];
  resultPath: string | null;
  createdAt: string;
  error?: string;
};

const DEFAULT_BASE_URL =
  (typeof process !== 'undefined' && process.env.NEXT_PUBLIC_WORKER_URL) || 'http://localhost:4000';

type ClientOptions = { baseUrl?: string; fetchFn?: typeof fetch };

export async function createJob(
  youtubeUrl: string,
  characterImage: File,
  { baseUrl = DEFAULT_BASE_URL, fetchFn = fetch }: ClientOptions = {},
): Promise<Job> {
  const form = new FormData();
  form.append('youtubeUrl', youtubeUrl);
  form.append('characterImages', characterImage);

  const res = await fetchFn(`${baseUrl}/jobs`, { method: 'POST', body: form });
  if (!res.ok) {
    const body = await res.json().catch(() => ({}) as { error?: string });
    throw new Error(body.error ?? `작업 생성 실패 (status ${res.status})`);
  }
  return res.json();
}

export async function getJob(
  id: string,
  { baseUrl = DEFAULT_BASE_URL, fetchFn = fetch }: ClientOptions = {},
): Promise<Job> {
  const res = await fetchFn(`${baseUrl}/jobs/${id}`);
  if (!res.ok) {
    throw new Error(`작업 조회 실패: ${id} (status ${res.status})`);
  }
  return res.json();
}

export function resultUrl(jobId: string, { baseUrl = DEFAULT_BASE_URL }: { baseUrl?: string } = {}): string {
  return `${baseUrl}/jobs/${jobId}/result`;
}
```

```tsx
'use client';

import { Handle, Position, type NodeProps } from '@xyflow/react';
import type { Job } from '../../lib/workerApi';

export type GenerateStatusNodeData = { job: Job | null };

type Tone = 'idle' | 'active' | 'done' | 'failed';

function summarize(job: Job | null): { text: string; tone: Tone } {
  if (!job) return { text: '대기 중', tone: 'idle' };
  if (job.status === 'failed') {
    return { text: `실패: ${job.error ?? '알 수 없는 오류'}`, tone: 'failed' };
  }
  if (job.status === 'downloading') return { text: '다운로드 중', tone: 'active' };
  if (job.status === 'segmenting') return { text: '분할 중', tone: 'active' };
  if (job.status === 'generating') {
    const done = job.segments.filter((s) => s.status === 'done').length;
    return { text: `생성 중 (${done}/${job.segments.length})`, tone: 'active' };
  }
  if (job.status === 'merging' || job.status === 'done') {
    const done = job.segments.filter((s) => s.status === 'done').length;
    return { text: `완료 (${done}/${job.segments.length})`, tone: 'done' };
  }
  return { text: '대기 중', tone: 'idle' };
}

const toneClasses: Record<Tone, string> = {
  idle: 'border-slate-700 bg-slate-900 text-slate-400',
  active: 'border-amber-500 bg-amber-950 text-amber-200',
  done: 'border-emerald-500 bg-emerald-950 text-emerald-200',
  failed: 'border-red-500 bg-red-950 text-red-200',
};

export function GenerateStatusNode({ data }: NodeProps & { data: GenerateStatusNodeData }) {
  const { text, tone } = summarize(data.job);
  return (
    <div className={`w-56 rounded-lg border p-3 shadow-lg ${toneClasses[tone]}`}>
      <Handle type="target" position={Position.Left} />
      <div className="mb-1 text-xs font-semibold uppercase tracking-wide opacity-70">생성</div>
      <div className="text-sm">{text}</div>
      <Handle type="source" position={Position.Right} />
    </div>
  );
}
```

```tsx
import { Handle, Position, type NodeProps } from '@xyflow/react';

export type MergeStatusNodeData = { job: Job | null };

function summarize(job: Job | null): { text: string; tone: Tone } {
  if (!job) return { text: '대기 중', tone: 'idle' };

    return { text: job.status === 'failed' ? '이전 단계 실패' : '대기 중', tone: 'failed' };

}

  idle: 'border-slate-700 bg-slate-900 text-slate-400',
  active: 'border-amber-500 bg-amber-950 text-amber-200',
  done: 'border-emerald-500 bg-emerald-950 text-emerald-200',
  failed: 'border-red-500 bg-red-950 text-red-200',
};

export function MergeStatusNode({ data }: NodeProps & { data: MergeStatusNodeData }) {
  const { text, tone } = summarize(data.job);
```

**Files:**

**Interfaces:**

- Produces: `Canvas` — Task 5(`app/page.tsx`)가 렌더링함

이 태스크도 상태 관리 로직이 핵심이라 자동 테스트보다 **수동 브라우저 검증**(Task 5에서 함께 진행)이 적합함. 다만 React Flow의 `useNodesState`를 써서 **드래그로 옮긴 노드 위치가 데이터 갱신 후에도 유지**되도록 하는 게 핵심 — `setNodes`로 전체 배열을 새로 만들지 않고, 기존 노드의 `data` 필드만 갱신하는 방식으로 구현.

- [ ] **Step 1: Canvas 컴포넌트 작성**

`web/components/Canvas.tsx`:

```tsx
'use client';

import { useCallback, useEffect, useRef, useState } from 'react';
import {
  ReactFlow,
  Background,
  Controls,
  addEdge,
  useNodesState,
  useEdgesState,
  type Node,
  type Edge,
  type Connection,
} from '@xyflow/react';
import '@xyflow/react/dist/style.css';
import { VideoInputNode, type VideoInputNodeData } from './nodes/VideoInputNode';
import { CharacterInputNode, type CharacterInputNodeData } from './nodes/CharacterInputNode';
import { GenerateStatusNode, type GenerateStatusNodeData } from './nodes/GenerateStatusNode';
import { MergeStatusNode, type MergeStatusNodeData } from './nodes/MergeStatusNode';
import { ResultNode, type ResultNodeData } from './nodes/ResultNode';
import { createJob, getJob, resultUrl, type Job } from '../lib/workerApi';

const nodeTypes = {
  videoInput: VideoInputNode,
  characterInput: CharacterInputNode,
  generateStatus: GenerateStatusNode,
  mergeStatus: MergeStatusNode,
  result: ResultNode,
};

type AnyNodeData =
  | VideoInputNodeData
  | CharacterInputNodeData
  | GenerateStatusNodeData
  | MergeStatusNodeData
  | ResultNodeData;

const POLL_INTERVAL_MS = 2000;

function buildInitialNodes(): Node<AnyNodeData>[] {
  return [
    {
      id: 'video-input',
      type: 'videoInput',
      position: { x: 0, y: 0 },
      data: { url: '', onUrlChange: () => {}, disabled: false },
    },
    {
      id: 'character-input',
      type: 'characterInput',
      position: { x: 0, y: 180 },
      data: { fileName: null, onFileChange: () => {}, disabled: false },
    },
    {
      id: 'generate',
      type: 'generateStatus',
      position: { x: 340, y: 90 },
      data: { job: null },
    },
    {
      id: 'merge',
      type: 'mergeStatus',
      position: { x: 660, y: 90 },
      data: { job: null },
    },
    {
      id: 'result',
      type: 'result',
      position: { x: 980, y: 90 },
      data: { job: null, resultUrl: null },
    },
  ];
}

const initialEdges: Edge[] = [
  { id: 'e-video-generate', source: 'video-input', target: 'generate' },
  { id: 'e-character-generate', source: 'character-input', target: 'generate' },
  { id: 'e-generate-merge', source: 'generate', target: 'merge' },
  { id: 'e-merge-result', source: 'merge', target: 'result' },
];

export function Canvas() {
  const [nodes, setNodes, onNodesChange] = useNodesState<Node<AnyNodeData>>(buildInitialNodes());
  const [edges, setEdges, onEdgesChange] = useEdgesState<Edge>(initialEdges);

  const [url, setUrl] = useState('');
  const [characterFile, setCharacterFile] = useState<File | null>(null);
  const [job, setJob] = useState<Job | null>(null);
  const [errorMessage, setErrorMessage] = useState<string | null>(null);
  const [isSubmitting, setIsSubmitting] = useState(false);
  const pollRef = useRef<ReturnType<typeof setInterval> | null>(null);

  const isRunning = job !== null && job.status !== 'done' && job.status !== 'failed';

  const stopPolling = useCallback(() => {
    if (pollRef.current) {
      clearInterval(pollRef.current);
      pollRef.current = null;
    }
  }, []);

  useEffect(() => stopPolling, [stopPolling]);

  const handleRun = useCallback(async () => {
    if (!url || !characterFile) {
      setErrorMessage('유튜브 URL과 캐릭터 이미지를 모두 입력해주세요.');
      return;
    }
    setErrorMessage(null);
    setIsSubmitting(true);
    try {
      const created = await createJob(url, characterFile);
      setJob(created);
      stopPolling();
      pollRef.current = setInterval(async () => {
        try {
          const updated = await getJob(created.id);
          setJob(updated);
          if (updated.status === 'done' || updated.status === 'failed') {
            stopPolling();
          }
        } catch {
          // 스펙 §8: 폴링 중 네트워크 오류는 조용히 다음 폴링에서 재시도 (배너 없음, YAGNI).
          // 워커가 완전히 죽은 경우 무한 재시도가 되지만, 개인용 로컬 도구 규모에서는
          // 사용자가 워커 로그를 직접 보고 문제를 알아채는 것으로 충분하다고 판단함.
        }
      }, POLL_INTERVAL_MS);
    } catch (error) {
      setErrorMessage(error instanceof Error ? error.message : '작업 생성에 실패했습니다.');
    } finally {
      setIsSubmitting(false);
    }
  }, [url, characterFile, stopPolling]);

  // 노드 위치(드래그 결과)는 useNodesState가 자체적으로 유지함.
  // 여기서는 각 노드의 `data`만 최신 상태로 갱신 — 위치는 건드리지 않음.
  useEffect(() => {
    setNodes((current) =>
      current.map((node) => {
        if (node.id === 'video-input') {
          const data: VideoInputNodeData = { url, onUrlChange: setUrl, disabled: isRunning };
          return { ...node, data };
        }
        if (node.id === 'character-input') {
          const data: CharacterInputNodeData = {
            fileName: characterFile?.name ?? null,
            onFileChange: setCharacterFile,
            disabled: isRunning,
          };
          return { ...node, data };
        }
        if (node.id === 'generate') {
          const data: GenerateStatusNodeData = { job };
          return { ...node, data };
        }
        if (node.id === 'merge') {
          const data: MergeStatusNodeData = { job };
          return { ...node, data };
        }
        if (node.id === 'result') {
          const data: ResultNodeData = { job, resultUrl: job ? resultUrl(job.id) : null };
          return { ...node, data };
        }
        return node;
      }),
    );
  }, [url, characterFile, job, isRunning, setNodes]);

  const onConnect = useCallback(
    (connection: Connection) => setEdges((eds) => addEdge(connection, eds)),
    [setEdges],
  );

  return (
    <div className="relative h-screen w-screen bg-slate-950">
      {errorMessage && (
        <div className="absolute left-1/2 top-4 z-10 -translate-x-1/2 rounded bg-red-900/90 px-4 py-2 text-sm text-red-100 shadow-lg">
          {errorMessage}
        </div>
      )}
      <button
        onClick={handleRun}
        disabled={isSubmitting || isRunning}
        className="absolute left-4 top-4 z-10 rounded-lg bg-emerald-600 px-4 py-2 font-semibold text-white shadow-lg hover:bg-emerald-500 disabled:cursor-not-allowed disabled:bg-slate-700"
      >
        {isRunning ? '생성 중...' : '실행'}
      </button>
      <ReactFlow
        nodes={nodes}
        edges={edges}
        nodeTypes={nodeTypes}
        onNodesChange={onNodesChange}
        onEdgesChange={onEdgesChange}
        onConnect={onConnect}
        fitView
      >
        <Background />
        <Controls />
      </ReactFlow>
    </div>
  );
}
```
